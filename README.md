# Fracture Detection AI

This project implements a two-stage, explainable AI framework for musculoskeletal X-ray fracture detection using the MURA dataset.  
Stage 1: Bone type classification (EfficientNet-B3).  
Stage 2: Fracture detection per bone (EfficientNet-B0 by default).  
The framework also provides Grad-CAM++ heatmaps for interpretability and generates diagnostic summaries using an external language model.

## Setup

1. **Install dependencies**
```bash
pip install -r requirements.txt
```

2. **Prepare data**  
Run these scripts in sequence (update dataset paths as required):
```bash
python src/data_preprocessing.py
python src/data_augmentation.py
python src/merge_datasets.py
python src/create_csv.py
```

3. **Train models**
- Bone classifier:
```bash
python src/bone_classification.py
```
- Fracture detection (per bone):
```bash
python src/fracture_detection.py
```

4. **Launch web interface**
```bash
streamlit run src/streamlit_app.py
```

---

## Models
- Bone classifier: EfficientNet-B3  
- Fracture detector: EfficientNet-B0 (per bone)  
- Explainability: Grad-CAM++  
- Diagnostic summaries: generated via external API (not included here)

### About trained weights
Trained model weights (`.pth`) should be placed in the `models/` directory.  
They are **not included in this package** due to file size constraints.  
If needed, they can be regenerated by running the training scripts, or provided separately upon request.
